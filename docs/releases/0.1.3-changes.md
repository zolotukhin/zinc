### Inkling 2 Mini on AMD RDNA4

The Linux ROCm and Vulkan builds run Inkling 2 Mini Q4_0 text inference on the
16 GB Radeon RX 9070 XT and 32 GB Radeon AI PRO R9700. Start with a 4,096-token
context and one request slot.

```bash
zinc model pull inkling-2-mini-q4-0
zinc chat --model-id inkling-2-mini-q4-0 --context 4096 --parallel 1
```

ROCm can use the optional Q8_0 DSpark draft model. See the
[Inkling setup guide](https://zolotukhin.ai/zinc/docs/running-zinc/#inkling-2-mini-on-amd-rdna4).
